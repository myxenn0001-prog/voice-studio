# Security

Voice Studio runs on your own computer and, by default, only accepts connections from that computer
(`127.0.0.1`). It has no accounts and sends nothing to a server of ours.

## Reporting a problem

Please do **not** open a public issue for a security problem. Email myofficialemail89@gmail.com with what you found and how to
reproduce it. We will reply as soon as we can and credit you in the fix if you wish.

## Good to know

- If you change the host setting so other devices can reach the app, anyone on that network can use it and
  read your renders. Do this only on a network you trust.
- Models and libraries are downloaded from the Hugging Face Hub and the Python Package Index on first launch.
